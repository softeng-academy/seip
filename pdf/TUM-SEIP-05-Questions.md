
AF-04.1: Architecture Maxims
============================

-  BLOOM: 4: Analyze
-  TYPE:  Case Study / Scenario Analysis
-  KIND:  free answer

After joining a project, you notice the following: (1) For years, the lead architect has not
written any code and has never worked with the solution. (2) The important architecture decisions
exist only in the heads of a few team members. (3) For six months, no code was written, because
the architecture was polished until it was as good as ultimately possible. (4) A single 400-page
document describes the architecture for all stakeholders. Identify for each observation the
violated Architecture Maxim and briefly justify it.
